# CineVault 🎬
 
A simple, private movie/show/anime tracker built with plain HTML, CSS, and JavaScript — no frameworks, no build step.
 
## Features
 
- **Track anything** — movies, TV shows, or anime, each with title, year, genre, category, and status.
- **Status tracking** — move items between Watchlist, Watching, and Completed.
- **Favorites** — mark items you love for quick access.
- **Continue Watching row** — see what's in progress right on the home page.
- **Add content modal** — add new items with a poster from a URL or uploaded directly from your device.
- **Statistics tab** — quick overview of your collection (totals, watching, completed, etc.).
- **Persistent storage** — everything is saved in the browser's `localStorage`, so your vault survives page reloads.
